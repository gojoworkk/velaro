# Календарь занятости — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** подтверждённые заявки и ручные блокировки занимают даты машины; сервер не принимает и не подтверждает пересекающиеся брони; сайт показывает свой календарь с зачёркнутыми днями; в админке — общий календарь месяца и блокировки.

**Architecture:** `lib/availability.ts` — правила пересечения, поиск конфликтов, занятость для сайта, блокировка машины (`pg_advisory_xact_lock`). Новая таблица `car_blocks`. `lib/admin/calendar.ts` — сетка месяца и блокировки. Каталог `/api/catalog` отдаёт занятые периоды (только даты). Лендинг — свой календарь в `public/script.js` вместо `<input type="date">`.

**Tech Stack:** Next.js 15.5, React 19, Drizzle 0.45 + pg, Vitest 3 + PGlite, ванильный JS на лендинге.

**Spec:** `docs/superpowers/specs/2026-10-18-calendar-design.md`

## Global Constraints

- Занимают даты: заявки `status IN ('confirmed','completed')` и записи `car_blocks`. Периоды включительные: пересечение `a.from <= b.to && b.from <= a.to`.
- Тексты ошибок: заявка с сайта — «Эти даты уже заняты — выберите другие или другую машину.» (ключ `dateFrom`); подтверждение — «Даты заняты: заявка №5, 20–23 октября» / «Даты закрыты: ТО, 20–23 октября»; блокировка — «Пересекается: заявка №5, 20–23 октября. Сначала отмените или перенесите её.» / «Пересекается с другой блокировкой: ТО, 20–23 октября.»
- Переход в `completed` — без проверки занятости. Проверка + запись — в транзакции под `pg_advisory_xact_lock(hashtext('car:' || car_id))`.
- Аренда не длиннее 365 суток («Аренда — не дольше 365 суток.», ключ `dateTo`). Блокировка: конец не раньше сегодня, начало не позже чем через 2 года, причина 1–100 символов.
- Каталог: `busy` — только будущие периоды (конец ≥ сегодня по Москве), начало ≤ сегодня + 13 месяцев, слитые; никаких имён/телефонов/номеров/причин.
- Тестовые данные — только в отдельной локальной базе (память `local-admin-testing`); перед стартом PGlite-сервера убедиться, что порт 5433 свободен, после — останавливать процесс по порту (TaskStop оставляет сирот).
- `public/index.html` и `public/script.js` — CRLF: правки только скриптом Python с `newline=''`, который приводит файл к CRLF; не `sed -i`.

import { and, eq, gte, inArray, lte, ne, sql, type SQL } from 'drizzle-orm';
import { carBlocks, requests } from '@/db/schema';
import type { AppDb } from '@/db/types';
import { dateRange } from './format';

export type Period = { from: string; to: string };
export type Conflict =
  | { kind: 'request'; id: number; from: string; to: string }
  | { kind: 'block'; id: number; reason: string; from: string; to: string };

/** Статусы заявок, которые занимают машину */
export const BUSY_STATUSES = ['confirmed', 'completed'] as const;

/** Периоды включительные: день возврата тоже занят */
export const overlaps = (a: Period, b: Period) => a.from <= b.to && b.from <= a.to;

export function addDays(iso: string, n: number): string {
  const d = new Date(`${iso}T00:00:00Z`);
  d.setUTCDate(d.getUTCDate() + n);
  return d.toISOString().slice(0, 10);
}

/** Сортирует и сливает пересекающиеся и соседние периоды */
export function mergePeriods(list: Period[]): [string, string][] {
  const sorted = [...list].sort((a, b) => (a.from < b.from ? -1 : a.from > b.from ? 1 : 0));
  const out: [string, string][] = [];
  for (const p of sorted) {
    const last = out.at(-1);
    if (last && p.from <= addDays(last[1], 1)) {
      if (p.to > last[1]) last[1] = p.to;
    } else {
      out.push([p.from, p.to]);
    }
  }
  return out;
}

export async function findConflicts(
  db: AppDb,
  carId: string,
  period: Period,
  opts: { excludeRequestId?: number } = {},
): Promise<Conflict[]> {
  const reqConds: SQL[] = [
    eq(requests.carId, carId),
    inArray(requests.status, [...BUSY_STATUSES]),
    lte(requests.dateFrom, period.to),
    gte(requests.dateTo, period.from),
  ];
  if (opts.excludeRequestId) reqConds.push(ne(requests.id, opts.excludeRequestId));
  const reqs = await db
    .select({ id: requests.id, from: requests.dateFrom, to: requests.dateTo })
    .from(requests)
    .where(and(...reqConds));
  const blocks = await db
    .select({ id: carBlocks.id, reason: carBlocks.reason, from: carBlocks.dateFrom, to: carBlocks.dateTo })
    .from(carBlocks)
    .where(and(eq(carBlocks.carId, carId), lte(carBlocks.dateFrom, period.to), gte(carBlocks.dateTo, period.from)));
  return [
    ...reqs.map((r) => ({ kind: 'request' as const, ...r })),
    ...blocks.map((b) => ({ kind: 'block' as const, ...b })),
  ].sort((a, b) => (a.from < b.from ? -1 : 1));
}

export function describeConflict(c: Conflict): string {
  const when = dateRange(c.from, c.to);
  return c.kind === 'request' ? `заявка №${c.id}, ${when}` : `${c.reason}, ${when}`;
}

/** Занятые периоды машин для сайта: только даты, только будущее, на 13 месяцев вперёд */
export async function busyByCar(db: AppDb, today: string): Promise<Record<string, [string, string][]>> {
  const horizon = addDays(today, 400);
  const reqs = await db
    .select({ carId: requests.carId, from: requests.dateFrom, to: requests.dateTo })
    .from(requests)
    .where(and(inArray(requests.status, [...BUSY_STATUSES]), gte(requests.dateTo, today), lte(requests.dateFrom, horizon)));
  const blocks = await db
    .select({ carId: carBlocks.carId, from: carBlocks.dateFrom, to: carBlocks.dateTo })
    .from(carBlocks)
    .where(and(gte(carBlocks.dateTo, today), lte(carBlocks.dateFrom, horizon)));
  const byCar: Record<string, Period[]> = {};
  for (const p of [...reqs, ...blocks]) (byCar[p.carId] ??= []).push({ from: p.from, to: p.to });
  return Object.fromEntries(Object.entries(byCar).map(([carId, list]) => [carId, mergePeriods(list)]));
}

/** Транзакция под блокировкой машины: две проверки занятости одной машины не идут параллельно */
export async function withCarLock<T>(db: AppDb, carId: string, fn: (tx: AppDb) => Promise<T>): Promise<T> {
  return db.transaction(async (tx) => {
    await tx.execute(sql`select pg_advisory_xact_lock(hashtext(${`car:${carId}`}))`);
    return fn(tx as unknown as AppDb);
  });
}

export async function monthGrid(db: AppDb, month: string, today: string): Promise<MonthGrid> {
  const { first, last } = monthBounds(month);
  const days: MonthGrid['days'] = [];
  for (let iso = first; iso <= last; iso = addDays(iso, 1)) {
    const dow = new Date(`${iso}T00:00:00Z`).getUTCDay();
    days.push({ iso, day: Number(iso.slice(8)), weekend: dow === 0 || dow === 6, today: iso === today });
  }
  const bar = (kind: Bar['kind'], id: number, label: string, from: string, to: string): Bar => {
    const a = from < first ? first : from;
    const b = to > last ? last : to;
    const start = Number(a.slice(8));
    return { kind, id, label, from, to, start, span: Number(b.slice(8)) - start + 1, cutStart: from < first, cutEnd: to > last };

    .select({ id: requests.id, carId: requests.carId, name: requests.name, from: requests.dateFrom, to: requests.dateTo })
    .from(requests)
    .where(and(inArray(requests.status, [...BUSY_STATUSES]), lte(requests.dateFrom, last), gte(requests.dateTo, first)));
  const blocks = await db
    .select({ id: carBlocks.id, carId: carBlocks.carId, reason: carBlocks.reason, from: carBlocks.dateFrom, to: carBlocks.dateTo })

  };

export async function addBlock(
  db: AppDb,
  actor: SessionUser,
  raw: { carId: unknown; from: unknown; to: unknown; reason: unknown },
  today: string,
  now: Date,
): Promise<{ ok: true } | { ok: false; errors: Record<string, string> }> {
  const errors: Record<string, string> = {};
  const carId = String(raw.carId ?? '');
  const from = String(raw.from ?? '');
  const to = String(raw.to ?? '');
  const reason = String(raw.reason ?? '').trim();
  const [car] = carId ? await db.select({ id: cars.id }).from(cars).where(eq(cars.id, carId)) : [];
  if (!car) errors.carId = 'Выберите машину.';
  if (!isIso(from)) errors.from = 'Укажите дату начала.';
  else if (from > addDays(today, 730)) errors.from = 'Не дальше чем на 2 года вперёд.';
  if (!isIso(to)) errors.to = 'Укажите дату окончания.';
  else if (isIso(from) && to < from) errors.to = 'Окончание не может быть раньше начала.';
  else if (to < today) errors.to = 'Дата окончания уже прошла.';
  if (!reason || reason.length > 100) errors.reason = 'Укажите причину (до 100 символов).';
  if (Object.keys(errors).length) return { ok: false, errors };

  return withCarLock(db, carId, async (tx) => {
    const [c] = await findConflicts(tx, carId, { from, to });
    if (c) {
      const form = c.kind === 'request'
        ? `Пересекается: ${describeConflict(c)}. Сначала отмените или перенесите её.`
        : `Пересекается с другой блокировкой: ${describeConflict(c)}.`;
      return { ok: false as const, errors: { form } };
    }
    await tx.insert(carBlocks).values({ carId, dateFrom: from, dateTo: to, reason, createdBy: actor.id, createdAt: now });
    return { ok: true as const };
  });
}

export async function removeBlock(db: AppDb, id: number): Promise<void> {
  if (Number.isInteger(id)) await db.delete(carBlocks).where(eq(carBlocks.id, id));
}

    })
    .from(carBlocks)
    .innerJoin(cars, eq(cars.id, carBlocks.carId))
    .innerJoin(users, eq(users.id, carBlocks.createdBy))
    .where(and(lte(carBlocks.dateFrom, last), gte(carBlocks.dateTo, first)))
    .orderBy(asc(carBlocks.dateFrom));
}
