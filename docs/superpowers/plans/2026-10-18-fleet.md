# Автопарк, цены и скидки из админки — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** владелец и менеджеры ведут машины, цены, депозиты, фото и скидки за срок в админке; сайт и расчёт заявок берут всё это из базы; каждое изменение цен пишется в журнал.

**Architecture:** новые поля `cars` (фото) и таблицы `discount_tiers`, `price_changes`. Логика — `lib/admin/fleet.ts` (правки + журнал), `lib/tiers.ts` (скидки из базы), `lib/catalog.ts` (данные для сайта), `lib/photo-store.ts` (Vercel Blob / локальная папка). Сайт берёт `GET /api/catalog` при загрузке и при сбое остаётся на встроенном списке. Админка — страницы `/admin/cars*` и серверные функции в `app/admin/actions.ts`.

**Tech Stack:** Next.js 15.5 (App Router, server actions), React 19, Drizzle 0.45 + pg, Vitest 3 + PGlite, `@vercel/blob`.

**Spec:** `docs/superpowers/specs/2026-10-18-fleet-design.md`

## Global Constraints

- Править автопарк и скидки могут **все** сотрудники админки (владелец и менеджеры); права проверяются `requireUser()` в каждой серверной функции.
- Машины не удаляются — только «скрыть». Классы фиксированы: `sport` Спорт, `suv` Внедорожники, `business` Бизнес.
- Ровно 4 ступени скидок; первая всегда с 1 суток; «от N суток» строго возрастает; N ≤ 365; процент — целое 0–90.
- Проверки машины: название 2–60; мощность 50–2000; разгон 1,5–20 (хранится строкой «3,3»); мест 1–9; цена и депозит — целые 1 000–10 000 000; подпись к фото до 200; положение кадра `^\d{1,3}% \d{1,3}%$`; фото JPG/PNG/WebP, 1 байт – 8 МБ.
- Журнал (`price_changes.kind`): `price`, `deposit`, `tier_percent`, `tier_days`, `created`, `hidden`, `shown`.
- Сервер считает цену заявки только по базе (цена машины + скидки из `discount_tiers`).
- `/api/catalog` кэшируется на CDN `CDN-Cache-Control: max-age=15, stale-while-revalidate=60`, браузеру — `Cache-Control: public, max-age=0, must-revalidate` — правка видна на сайте в течение ~15 секунд.
- Тестовые аккаунты и данные — только в отдельной локальной базе (см. память `local-admin-testing`), не в Neon из `.env.local`.
- Тексты — по-русски. Коммиты от `gojoworkk <194110524+gojoworkk@users.noreply.github.com>`, в конце `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Ветка `feature/fleet`.

```ts
export type Tier = { minDays: number; percent: number };

/** Скидки за срок по умолчанию — если в базе их нет. Ступени по возрастанию minDays */
export const DEFAULT_TIERS: readonly Tier[] = [
  { minDays: 1, percent: 0 },
  { minDays: 3, percent: 10 },
  { minDays: 7, percent: 20 },
  { minDays: 14, percent: 30 },
];

const DAY_MS = 86_400_000;
const toUtc = (iso: string) => Date.parse(`${iso}T00:00:00Z`);

/** Сутки аренды: разница дат, в один день — 1 сутки */
export function countDays(from: string, to: string): number {
  return Math.max(1, Math.round((toUtc(to) - toUtc(from)) / DAY_MS));
}

/** Скидка долей: 0.1 = 10% */
export function discountFor(days: number, tiers: readonly Tier[] = DEFAULT_TIERS): number {
  let percent = 0;
  for (const tier of tiers) if (days >= tier.minDays) percent = tier.percent;
  return percent / 100;
}

/** Цена за сутки со скидкой, округлённая до 100 ₽ */
export function dayRate(pricePerDay: number, days: number, tiers: readonly Tier[] = DEFAULT_TIERS): number {
  return Math.round((pricePerDay * (1 - discountFor(days, tiers))) / 100) * 100;
}

export function quote(pricePerDay: number, from: string, to: string, tiers: readonly Tier[] = DEFAULT_TIERS) {
  const days = countDays(from, to);
  const rate = dayRate(pricePerDay, days, tiers);
  return { days, dayRate: rate, total: rate * days };
}
```

```ts
import { asc, eq } from 'drizzle-orm';
import { cars } from '@/db/schema';
import type { AppDb } from '@/db/types';
import type { Tier } from './pricing';
import { getTiers } from './tiers';

/** Машина в том виде, в каком её ждёт лендинг (как CARS в public/script.js) */
export type CatalogCar = {
  id: string; name: string; cat: 'sport' | 'suv' | 'business'; power: number; accel: string; seats: number;
  price: number; deposit: number; img: string; pos: string; alt: string;
};

export async function getCatalog(db: AppDb): Promise<{ cars: CatalogCar[]; tiers: Tier[] }> {
  const rows = await db.select().from(cars).where(eq(cars.active, true)).orderBy(asc(cars.sortOrder), asc(cars.id));
  return {
    cars: rows.map((c) => ({
      id: c.id, name: c.name, cat: c.category, power: c.powerHp, accel: c.accel0100, seats: c.seats,
      price: c.pricePerDay, deposit: c.deposit, img: c.photoUrl, pos: c.photoPos, alt: c.photoAlt,
    })),
    tiers: await getTiers(db),
  };
}
```

```ts
import { NextResponse } from 'next/server';

// Машины и скидки для лендинга. CDN держит ответ 15 секунд — правка из админки видна почти сразу

}
```

```ts
export type Category = keyof typeof CATEGORIES;

/** Положение кадра в карточке: object-position по вертикали */
export const PHOTO_POSITIONS: Record<string, string> = { '50% 35%': 'Выше', '50% 60%': 'По центру', '50% 80%': 'Ниже' };

export type CarInput = {

type Errors = Record<string, string>;

/** Целое из строки «70 000» → 70000; иначе NaN */
const int = (v: unknown) => {
  const s = String(v ?? '').replace(/[\s ]/g, '');
  return /^-?\d+$/.test(s) ? Number(s) : Number.NaN;
};
const between = (n: number, lo: number, hi: number) => Number.isInteger(n) && n >= lo && n <= hi;

export function validateCar(raw: Record<string, unknown>): { ok: true; data: CarInput } | { ok: false; errors: Errors } {
  const errors: Errors = {};
  const name = String(raw.name ?? '').trim();
  if (name.length < 2 || name.length > 60) errors.name = 'Название — от 2 до 60 символов.';
  const category = String(raw.category ?? '');
  if (!(category in CATEGORIES)) errors.category = 'Выберите класс.';
  const powerHp = int(raw.powerHp);
  if (!between(powerHp, 50, 2000)) errors.powerHp = 'Мощность — от 50 до 2000 л.с.';
  const accelText = String(raw.accel0100 ?? '').trim().replace(',', '.');
  const accel = /^\d+(\.\d+)?$/.test(accelText) ? Number(accelText) : Number.NaN;
  if (!(accel >= 1.5 && accel <= 20)) errors.accel0100 = 'Разгон до сотни — от 1,5 до 20 секунд.';
  const seats = int(raw.seats);
  if (!between(seats, 1, 9)) errors.seats = 'Мест — от 1 до 9.';
  const pricePerDay = int(raw.pricePerDay);
  if (!between(pricePerDay, 1000, 10_000_000)) errors.pricePerDay = 'Цена — от 1 000 до 10 000 000 ₽.';
  const deposit = int(raw.deposit);
  if (!between(deposit, 1000, 10_000_000)) errors.deposit = 'Депозит — от 1 000 до 10 000 000 ₽.';
  const photoAlt = String(raw.photoAlt ?? '').trim();
  if (photoAlt.length > 200) errors.photoAlt = 'Подпись к фото — до 200 символов.';
  const photoPos = String(raw.photoPos ?? '50% 60%').trim();
  if (!/^\d{1,3}% \d{1,3}%$/.test(photoPos)) errors.photoPos = 'Выберите положение кадра.';
  if (Object.keys(errors).length) return { ok: false, errors };
  return {
    ok: true,
    data: {
      name, category: category as Category, powerHp, accel0100: accel.toFixed(1).replace('.', ','), seats,
      pricePerDay, deposit, photoAlt: photoAlt || name, photoPos, active: raw.active === true || raw.active === 'on',
    },
  };
}

const TRANSLIT: Record<string, string> = {
  а: 'a', б: 'b', в: 'v', г: 'g', д: 'd', е: 'e', ё: 'e', ж: 'zh', з: 'z', и: 'i', й: 'y', к: 'k', л: 'l', м: 'm',
  н: 'n', о: 'o', п: 'p', р: 'r', с: 's', т: 't', у: 'u', ф: 'f', х: 'h', ц: 'ts', ч: 'ch', ш: 'sh', щ: 'sch',
  ъ: '', ы: 'y', ь: '', э: 'e', ю: 'yu', я: 'ya',
};

/** «Lamborghini Huracán EVO» → «lamborghini-huracan-evo» */
export function slugify(name: string): string {
  const latin = [...name.toLowerCase()].map((ch) => TRANSLIT[ch] ?? ch).join('');
  const slug = latin.normalize('NFKD').replace(/[̀-ͯ]/g, '').replace(/[^a-z0-9]+/g, '-').replace(/^-+|-+$/g, '').slice(0, 40).replace(/-+$/, '');
  return slug || 'car';
}

export async function nextCarId(db: AppDb, name: string): Promise<string> {
  const base = slugify(name);
  for (let n = 1; ; n++) {
    const id = n === 1 ? base : `${base}-${n}`;
    const [taken] = await db.select({ id: cars.id }).from(cars).where(eq(cars.id, id));
    if (!taken) return id;
  }
}

const carFields = (input: CarInput) => ({
  name: input.name, category: input.category, powerHp: input.powerHp, accel0100: input.accel0100, seats: input.seats,

export async function createCar(db: AppDb, actor: SessionUser, id: string, input: CarInput, photoUrl: string, now: Date): Promise<void> {
  const [{ last }] = await db.select({ last: max(cars.sortOrder) }).from(cars);
  await db.insert(cars).values({ id, ...carFields(input), photoUrl, sortOrder: (last ?? -1) + 1, updatedAt: now });
  await logChange(db, actor, now, { kind: 'created', carId: id, toValue: input.pricePerDay });
}

export async function updateCar(
  db: AppDb, actor: SessionUser, id: string, input: CarInput, photoUrl: string | null, now: Date,
): Promise<{ ok: true; oldPhotoUrl: string | null } | { ok: false; error: string }> {
  const cur = await getCar(db, id);
  if (!cur) return { ok: false, error: 'Машина не найдена.' };
  await db.update(cars).set({ ...carFields(input), ...(photoUrl ? { photoUrl } : {}), updatedAt: now }).where(eq(cars.id, id));
  if (cur.pricePerDay !== input.pricePerDay) await logChange(db, actor, now, { kind: 'price', carId: id, fromValue: cur.pricePerDay, toValue: input.pricePerDay });
  if (cur.deposit !== input.deposit) await logChange(db, actor, now, { kind: 'deposit', carId: id, fromValue: cur.deposit, toValue: input.deposit });
  if (cur.active !== input.active) await logChange(db, actor, now, { kind: input.active ? 'shown' : 'hidden', carId: id });
  return { ok: true, oldPhotoUrl: photoUrl && photoUrl !== cur.photoUrl ? cur.photoUrl : null };
}

export async function setCarActive(db: AppDb, actor: SessionUser, id: string, active: boolean, now: Date): Promise<{ ok: true } | { ok: false; error: string }> {
  const cur = await getCar(db, id);
  if (!cur) return { ok: false, error: 'Машина не найдена.' };
  if (cur.active === active) return { ok: true };
  await db.update(cars).set({ active, updatedAt: now }).where(eq(cars.id, id));
  await logChange(db, actor, now, { kind: active ? 'shown' : 'hidden', carId: id });
  return { ok: true };
}

/** Сдвинуть машину на одну позицию; порядок заодно нормализуется в 0..n-1 */
export async function moveCar(db: AppDb, id: string, dir: -1 | 1): Promise<void> {
  const list = await db.select({ id: cars.id }).from(cars).orderBy(asc(cars.sortOrder), asc(cars.id));
  const i = list.findIndex((c) => c.id === id);
  const j = i + dir;
  if (i >= 0 && j >= 0 && j < list.length) [list[i], list[j]] = [list[j], list[i]];
  await db.transaction(async (tx) => {
    for (let k = 0; k < list.length; k++) await tx.update(cars).set({ sortOrder: k }).where(eq(cars.id, list[k].id));
  });
}

export async function saveTiers(
  db: AppDb, actor: SessionUser, rows: { minDays: unknown; percent: unknown }[], now: Date,
): Promise<{ ok: true } | { ok: false; errors: Errors }> {
  if (rows.length !== 4) return { ok: false, errors: { form: 'Нужно ровно 4 ступени скидок.' } };
  const errors: Errors = {};
  const next = rows.map((r, i) => ({ minDays: i === 0 ? 1 : int(r.minDays), percent: int(r.percent) }));
  next.forEach((t, i) => {
    const key = `tier${i + 1}`;
    if (!between(t.percent, 0, 90)) errors[key] = 'Скидка — целое число от 0 до 90%.';
    else if (i > 0 && !between(t.minDays, 2, 365)) errors[key] = 'Срок — целое число суток от 2 до 365.';
    else if (i > 0 && t.minDays <= next[i - 1].minDays) errors[key] = 'Срок должен быть больше, чем у предыдущей ступени.';
  });
  if (Object.keys(errors).length) return { ok: false, errors };

  const cur = await getTiers(db);
  for (let i = 0; i < 4; i++) {
    const t = next[i];
    await db.insert(discountTiers).values({ position: i + 1, ...t })
      .onConflictDoUpdate({ target: discountTiers.position, set: { minDays: t.minDays, percent: t.percent } });
    if (cur[i].percent !== t.percent) await logChange(db, actor, now, { kind: 'tier_percent', tier: i + 1, fromValue: cur[i].percent, toValue: t.percent });
    if (cur[i].minDays !== t.minDays) await logChange(db, actor, now, { kind: 'tier_days', tier: i + 1, fromValue: cur[i].minDays, toValue: t.minDays });
  }
  return { ok: true };
}

export type PriceLogRow = {
  id: number; createdAt: Date; authorName: string; carName: string | null; kind: PriceChangeKind;
  tier: number | null; fromValue: string | null; toValue: string | null;
};

export async function listPriceLog(db: AppDb, limit = 200): Promise<PriceLogRow[]> {
  return db
    .select({
      id: priceChanges.id, createdAt: priceChanges.createdAt, authorName: users.name, carName: cars.name,
      kind: priceChanges.kind, tier: priceChanges.tier, fromValue: priceChanges.fromValue, toValue: priceChanges.toValue,
    })
    .from(priceChanges)
    .innerJoin(users, eq(users.id, priceChanges.userId))
    .leftJoin(cars, eq(cars.id, priceChanges.carId))
    .orderBy(desc(priceChanges.createdAt), desc(priceChanges.id))
    .limit(limit);
}

const money = (v: string | null) => rub(Number(v ?? 0));

/** Строка журнала: «Mercedes-AMG G 63: цена 65 000 ₽ → 70 000 ₽» */
export function describeChange(r: PriceLogRow): string {
  const car = r.carName ?? 'Машина';
  switch (r.kind) {
    case 'price': return `${car}: цена ${money(r.fromValue)} → ${money(r.toValue)}`;
    case 'deposit': return `${car}: депозит ${money(r.fromValue)} → ${money(r.toValue)}`;
    case 'created': return `${car}: добавлена, ${money(r.toValue)} в сутки`;
    case 'hidden': return `${car}: скрыта с сайта`;
    case 'shown': return `${car}: снова на сайте`;
    case 'tier_percent': return `Скидка ${r.tier}: ${r.fromValue}% → ${r.toValue}%`;
    case 'tier_days': return `Скидка ${r.tier}: от ${r.fromValue} → от ${r.toValue} суток`;
  }
}
```

```ts
export function localPhotoStore(root: string, urlPrefix = '/uploads'): PhotoStore {
  return {
    async put(name, data) {
      const file = path.join(root, name);
      await mkdir(path.dirname(file), { recursive: true });
      await writeFile(file, data);
      return `${urlPrefix}/${name}`;
    },

      await unlink(path.join(root, url.slice(urlPrefix.length + 1))).catch(() => {});
    },
  };

export function blobPhotoStore(token: string): PhotoStore {
  return {
    async put(name, data, contentType) {
      const { put } = await import('@vercel/blob');
      const blob = await put(name, data, { access: 'public', contentType, token });
      return blob.url;

      if (!/^https:\/\/[^/]+\.blob\.vercel-storage\.com\//.test(url)) return;
      const { del } = await import('@vercel/blob');
      await del(url, { token }).catch(() => {});
```

```ts
  if (!store) return { error: NO_STORE, values };
  const db = getDb();
  const id = await nextCarId(db, check.data.name);
  const url = await store.put(photoName(id, photo.type), Buffer.from(await photo.arrayBuffer()), photo.type);
  await createCar(db, user, id, check.data, url, new Date());
  revalidateFleet();
  redirect('/admin/cars');
}

export async function updateCarAction(id: string, _prev: ActionState, fd: FormData): Promise<ActionState> {
  const user = await requireUser();
  const { values, photo, check } = readCarForm(fd);
  const errors = { ...(check.ok ? {} : check.errors) };
  const pErr = photo ? photoError(photo) : null;
  if (pErr) errors.photo = pErr;
  if (!check.ok || pErr) return { errors, values };
  let url: string | null = null;
  let store: PhotoStore | null = null;
  if (photo) {
    store = photoStoreOrNull();
    if (!store) return { error: NO_STORE, values };
    url = await store.put(photoName(id, photo.type), Buffer.from(await photo.arrayBuffer()), photo.type);
  }
  const res = await updateCar(getDb(), user, id, check.data, url, new Date());
  if (!res.ok) return { error: res.error, values };
  if (store && res.oldPhotoUrl) await store.remove(res.oldPhotoUrl);
  revalidateFleet();
  redirect('/admin/cars');
}
```
